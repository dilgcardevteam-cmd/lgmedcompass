📅 Deadline Auto-Generation Demo

📋 How it works:

  1. Select a frequency (Monthly, Quarterly, or Annual)
  2. Enter the first non-N/A due date manually
  3. The system will automatically generate all subsequent due dates for empty fields only
  4. Weekend dates are automatically adjusted to Monday
  5. Auto-generated dates are fully editable! Change them as needed

🎯 Example:

If you select Quarterly and enter May 9, 2026, the system will generate:

  • May 9, 2026 (your input)
  • August 9, 2026 (+3 months) - auto-generated, editable
  • November 9, 2026 (+6 months) - auto-generated, editable
  • February 9, 2027 (+9 months) - auto-generated, editable

✨ New Behavior:

  • First non-N/A date triggers auto-generation
  • Only empty fields get auto-generated
  • Manual changes to auto-generated dates are preserved
  • N/A checkboxes work independently
